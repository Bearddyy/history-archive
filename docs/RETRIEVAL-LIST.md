# Retrieval / digitisation wish-list

digitising) to advance the open questions. Ordered by value-per-effort.
"Answers" names the KB entities/questions each document would settle.
Links: TNA Discovery pages are direct; HALS items are found in the catalogue
(https://www.hertfordshirearchives.org.uk/collections/search?s=REF) — Cloudflare
blocks machine access, open in a browser.

## Free-first strategy
- TNA reading room: IR 29/15/90, IR 29/15/56, IR 18 files are free to read; PROB
  images (item 4) are already free online.
- HALS searchroom: all DE/DSA/DP/D-EH items; E3 plan reproduction is the one
  worth paying for if visiting.
- TheGenealogist (subscription) holds IR 29 text+images if a visit isn't possible.
- AALT rotulus images for item 18 are free; direct link on the medievalgenealogy
  abstract page we mirror in raw/.
- EPNS field-name slips (English Place-Name Society archives, Cambridge/British
  Library collection office) — free with reader's card; would carry typed 1950s
  field-name collections for Stanstead incl. possibly Slap Ladies/Privis from
  local informants.
